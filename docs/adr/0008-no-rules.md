# No Rules

The app has no Rules (user-written instructions such as `.dmg` → Trash). The user acts on files only through the Plan: duplicates, Suggested Folders, and their own changes on the Review screen. Rules were built and then frozen; this makes their removal final, so the leftover rule code is to be deleted, not revived. This also closes finding C1 and step 7 of the user-control audit (#3), which suggested bringing them back.
